# Frontend Reference (`docs/frontend-ref/`)

Интерактивный референс дашборда **Live Truth Radar** по **Apple Human Interface Guidelines** (Light & Dark темы), сфокусированный на **интуитивной понятности сверху вниз** и объяснении идеи «на пальцах» для питча.

> **Handoff для переиспользования идеи с другим дизайном:** [`HANDOFF_EXPLAINABILITY.md`](HANDOFF_EXPLAINABILITY.md) — подробный разбор нашего подхода к UX, дизайн-независимая спецификация экранов, таблица маппинга «аналогия на пальцах ↔ интерактив ↔ формула DSP ↔ контракт API» и инструкция по переносу 3D-компонента `ambiguity3d.js`.

## Архитектура страниц (2 главные + 2 дополнительные)

1. **[index.html](index.html) — Главная #1: «Радар и итог»**
   - **Сверху (`#topic-form` + `#beam-pills`):** выбор активной темы потока или ввод любой своей темы (с тестовыми режимами `Рой` / `Эхо новости` / `Живые люди`) и кнопка **`⚡ Вбросить тестовый рой`**.
   - **По центру (`#status-center`):** концентрированное саммари с текущим статусом светофором, 1-строчным вердиктом, объяснением Gemini, цитатой, 3 ключевыми метриками и скрытыми под спойлер примерами постов.
   - **Ниже (`#ambiguity-showcase` + `ambiguity3d.js`):** широкое **3D-тело неопределённости** с выносками-указателями прямо на вершину пика и фон темы, а также 3 интерактивные карточки-указателя (`Вершина`, `Синий ковёр`, `Опасный угол`) для подсветки элементов в 3D.
2. **[how.html](how.html) — Главная #2: «Как это работает» (на пальцах, как детям)**
   - Интерактивный 5-шаговый сторителлинг по [signal-processing.md §3](../signal-processing.md) с бытовыми метафорами и спойлерами `🤓 Для жюри` для строгих формул:
     1. *🔦 Фонарик на тему* — слайдер ширины луча, в реальном времени подсвечивающий релевантные посты.
     2. *🧭 Тише, общий шум!* — интерактивный SVG-компас смысла «до / после» вычитания общего фона темы.
     3. *🧱 3D-гора из кубиков* — живой 3D-конструктор со слайдерами числа ботов и синхронности.
     4. *⚽ Гол или боты?* — тумблер срочной новости + ползунок запаса осторожности (OS-CFAR и защита от эха новости).
     5. *⚖️ Весы детектива* — наглядные чаши весов + шкала уверенности + пошаговая кривая SPRT с кнопками `+1 пост`.
3. **[details.html](details.html) — «Детали»**
   - Полная матрица кросс-корреляции аккаунтов с лагами (`lag_sec`), полная трасса SPRT, список всех аккаунтов (с переключателем `@ab***`), Source Trust (S1) и все посты группы.
4. **[metrics.html](metrics.html) — «Метрики» (`/metrics`)**
   - KPI, ROC-кривая, `Pd` от размера роя, `failure_examples` и переключатель состояния «заглушки» до `T13`.

## Как открыть
- Двойным кликом по [index.html](index.html) (работает даже через `file://`; инжектированные рои и кастомные пробы тем сохраняются в `sessionStorage` между страницами).
- Или через локальный сервер из корня репо:
  ```bash
  python3 -m http.server 8080
  # http://localhost:8080/docs/frontend-ref/index.html
  ```
