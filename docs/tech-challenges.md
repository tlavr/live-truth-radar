### Что умеет Context.dev
- **Web:** search, scrape (markdown, HTML, скриншоты, картинки), crawl, карта URL, **структурированное извлечение по JSON-схеме**, research-ответы.
- **Entities:** бренд-данные (лого, цвета, шрифты, стайлгайды), **поиск и обогащение компаний и людей**, классификация NAICS/SIC.
- **Signals:** **поиск новостей**, **мониторы с вебхуками для детекции изменений**.
- **Scale:** batch API на тысячи URL, парсинг PDF и документов.
- **Social media:** скрейп лент TikTok, Instagram (из описания тех-челленджа).
- SDK: TypeScript/Node, Python, Ruby, Go; CLI; agent skill; **MCP-сервер** `https://mcp.context.dev/mcp`; Playground без кода.

### Кредиты и доступ

### Технические советы от них
- Проверять флаг `success` в каждом ответе: 200 может содержать неудачу.
- `maxAgeMs: 0` для свежих данных: по умолчанию кэш **до 3 дней**, и кэш стоит столько же кредитов → храните результаты у себя.
- Crawl, batch и мониторы **асинхронные**: опрашивать job или принимать вебхук (для локалки — Cloudflare Tunnel). *На Hostinger VPS с публичным URL вебхук работает сразу!*
- Некоторые сайты блокируют автоматику; уважать их условия.
