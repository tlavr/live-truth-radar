## 1. Hostinger (основной челлендж Decode the Noise) · ✅ must
**Что даёт (1 месяц бесплатно):**
- **VPS KVM 2:** 2 vCPU, 8 ГБ RAM, 100 ГБ NVMe, Docker, root, **бесплатный домен**.
- **AI Router:** один ключ на 150+ моделей (Anthropic, OpenAI, DeepSeek, Mistral, xAI), совместим с OpenAI и Anthropic SDK.
- **Connector / API / MCP** (`github.com/hostinger/api-mcp-server`): деплой и домен прямо из редактора.

**Роль у нас:** Docker Compose на VPS: `api` (бэкенд + вебхуки), `worker` (детекторы), `db` (Postgres + pgvector), `web` (дашборд). Публичный HTTPS-домен сразу принимает вебхуки Context.dev. AI Router = запасной LLM (если упрёмся в лимиты Gemini) и показывает судьям, что мы используем их стек.

**Обязательно:** живой публичный URL к концу хакатона. 40% оценки = качество детекции и честные метрики.

## 2. Context.dev · ✅ ядро
**Условие приза:** ≥1 эндпоинт **в основном потоке**, данные **видимо управляют демо**. Сдать репо + демо + **заметку «какие эндпоинты и зачем»**.
**Судят:** 40% креатив (комбинация эндпоинтов), 30% центральность живых данных, 30% техника (точность, латентность, изменения во времени).
**Лимиты:** 50 000 кредитов на команду без срока, до 50 параллельных запросов, без rate limit.

| Эндпоинт | Что делает у нас | Модуль |
|---|---|---|
| **News search** | Поток свежих статей по теме | Live Ingest |
| **Monitors + webhooks** | Сигнал «тема/страница изменилась» → сразу на наш VPS | Live Ingest, Change Watch |
| **Social scrape** (TikTok, Instagram) | Посты + автор + время → временные ряды активности | Swarm Detector |
| **Scrape** (markdown, `maxAgeMs: 0`) | Полный текст статьи для анализа | Technique, Fact-check |
| **Structured extraction** (JSON-схема) | Достаём `claim`, `author`, `published_at`, ссылки | Все детекторы |
| **Brand + company enrichment** | Кто стоит за доменом, чужое ли лого | Source Trust |
| **Research** | Ответ с источниками на «правда ли X?» | Fact-check |

**Подводные камни:** проверять флаг `success` (200 бывает с ошибкой); кэш до 3 дней стоит тех же кредитов → сохранять результаты у себя; crawl, batch и monitors асинхронные.

## 3. Oxylabs Web API · ✅ берём
**Условие приза:** в демо **живой вызов** `/search` или `/scrape` (заранее скачанные данные не считаются) + показываем **URL источников**. В сабмит: заметка «какие эндпоинты и зачем».
**Судят:** 30% использование API, 25% ценность, 20% доверие (свежо, с источниками, честно о сбоях), 15% живое демо, 10% оригинальность.
**Доступ:** план Flexible с кодом из Hackerpack (100% скидка на 1 месяц). ⚠️ **Отменить подписку сразу после хакатона**, иначе спишут $500.

| Эндпоинт | Что делает у нас |
|---|---|
| `/search` с гео (FI, DE, EE, …) | Тот же нарратив всплывает в разных странах одновременно? → сигнал роя |
| `/scrape` (JS-рендер, обход бот-защиты) | Читаем страницы, которые Context.dev не открыл |
| Ответы ChatGPT / Perplexity / Google AI Mode | «Что говорит AI про этот нарратив» → не подхватили ли модели пропаганду |

## 4. Gemini API · ✅ берём
**Условие приза:** выйти **за рамки «добавили LLM»**. В сабмите объяснить: проблему, как интегрирован Gemini, что инновационно, почему без Gemini не работает. Ключ в Google AI Studio, **только 18+**.

**Роль у нас:**
- **Эмбеддинги** постов → согласованный фильтр (поиск нарратива, даже если перефразировали).
- **Technique Classifier** со structured output: приём + цитата-доказательство + уверенность.
- **Длинный контекст:** весь кластер роя (сотни постов) за один вызов → объяснение «почему это кампания».
- **Fact-check** с grounding и ссылками.

**Почему Gemini важен (для текста сабмита):** длинный контекст позволяет судить о группе, а не об одном посте, и это ровно наш «деспрединг».

## 6. Опционально и не берём
- **Gemma ◐.** EmbeddingGemma (~300M) запускается на CPU прямо на VPS → эмбеддинги без внешнего API и без лимитов. Берём, только если останется время: тогда это ещё €1000 (3 победителя без ранжирования).
- **Nemotron ❌.** Силён в картинках и видео, а у нас текст. Бесплатный API ~40 запросов в минуту на ключ, нужен отдельный текст в форме.
- **Modal / Verda ❌.** Им нужно, чтобы GPU был центральным (у Modal это 40% оценки). Нам GPU не нужен.
- **Aiven ❌.** Postgres + pgvector в Docker на VPS проще и держит всё на Hostinger.
