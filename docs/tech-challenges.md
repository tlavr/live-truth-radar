Пример, как это работает вместе: Context.dev приносит 40 новых постов про «отключение света» → Gemini превращает их в векторы → согласованный фильтр и корреляция находят рой из 17 аккаунтов → CFAR и SPRT говорят «координировано» при заданной доле ложных тревог → Gemini объясняет приём («запугивание») с цитатой → (SHOULD) Oxylabs показывает, что тот же нарратив всплыл в EE и DE, с URL источников.

**Правило для сабмита:** в тексте и в списке тех-челленджей оставляем только то, что **реально работает в демо**. Не сделали SHOULD — вычёркиваем.

## 1. Hostinger (основной челлендж Decode the Noise) · ✅ MUST
**Что даёт (1 месяц бесплатно):**
- **VPS KVM 2:** 2 vCPU, 8 ГБ RAM, 100 ГБ NVMe, Docker, root, **бесплатный домен**.
- **AI Router:** один ключ на 150+ моделей (Anthropic, OpenAI, DeepSeek, Mistral, xAI), совместим с OpenAI и Anthropic SDK.
- **Connector / API / MCP** (`github.com/hostinger/api-mcp-server`): деплой и домен прямо из редактора.

**Роль у нас:** Docker Compose на VPS: `caddy` (HTTPS), `api` (FastAPI + дашборд), `worker` (поллинг Context.dev, детекторы, Gemini, eval), `db` (Postgres + pgvector). AI Router = запасной LLM (если упрёмся в лимиты Gemini) и показывает судьям, что мы используем их стек.

**Обязательно:** живой публичный URL к концу хакатона. 40% оценки = качество детекции и честные метрики.

## 2. Context.dev · ✅ MUST, ядро
**Условие приза:** ≥1 эндпоинт **в основном потоке**, данные **видимо управляют демо**. Сдать репо + демо + **заметку «какие эндпоинты и зачем»**.
**Судят:** 40% креатив (комбинация эндпоинтов), 30% центральность живых данных, 30% техника (точность, латентность, изменения во времени).
**Лимиты:** 50 000 кредитов на команду без срока, до 50 параллельных запросов, без rate limit.

| Эндпоинт | Что делает у нас | Уровень |
|---|---|---|
| **News search** | Поток свежих статей по 3–5 темам (поллинг каждые 2–5 мин) | MUST |
| **Social scrape** (TikTok, Instagram) | Посты + автор + время → временные ряды активности для роя | MUST (**сначала проверить, что автор и время есть**) |
| **Scrape** (markdown, `maxAgeMs: 0`) | Полный текст статьи, если в выдаче поиска только сниппет | SHOULD |
| **Brand + company enrichment** | Кто стоит за доменом, чужое ли лого (Source Trust) → «комбинация эндпоинтов» для судей | SHOULD |
| Monitors + webhooks, Research, Structured extraction | Заменены поллингом / Fact-check вырезан | CUT |

**Подводные камни:** проверять флаг `success` (200 бывает с ошибкой); кэш до 3 дней стоит тех же кредитов → сохранять результаты у себя; crawl и batch асинхронные.

## 3. Gemini API · ✅ MUST
**Условие приза:** выйти **за рамки «добавили LLM»**. В сабмите объяснить: проблему, как интегрирован Gemini, что инновационно, почему без Gemini не работает. Ключ в Google AI Studio, **только 18+**.

**Роль у нас:**
- **Эмбеддинги** постов → согласованный фильтр (поиск нарратива, даже если перефразировали).
- **Technique Classifier** со structured output: приём + цитата-доказательство + уверенность.
- **Длинный контекст:** весь кластер роя (сотни постов) за один вызов → объяснение «почему это кампания».
- Генерация вариаций для синтетического роя (eval).

**Почему Gemini важен (для текста сабмита):** длинный контекст позволяет судить о группе, а не об одном посте, и это ровно наш «деспрединг».

## 4. Oxylabs Web API · ◐ SHOULD
**Условие приза:** в демо **живой вызов** `/search` или `/scrape` (заранее скачанные данные не считаются) + показываем **URL источников**. В сабмит: заметка «какие эндпоинты и зачем».
**Судят:** 30% использование API, 25% ценность, 20% доверие (свежо, с источниками, честно о сбоях), 15% живое демо, 10% оригинальность.
**Доступ:** план Flexible с кодом из Hackerpack (100% скидка на 1 месяц). ⚠️ **Отменить подписку сразу после хакатона** (шаг 18, C), иначе спишут $500. Активируем только когда дошли до шага 13.
**Честно:** челлендж называется «Best *agentic* usecase», а один гео-`/search` — скромное использование. Шансы на приз невысокие, поэтому это SHOULD, а не MUST.

| Эндпоинт | Что делает у нас | Уровень |
|---|---|---|
| `/search` с гео (FI, DE, EE, …) | Карточка вердикта: «тот же нарратив в других странах» + URL | SHOULD |
| `/scrape`, ответы ChatGPT / Perplexity / Google AI Mode | — | CUT |

## 5. Codex · ◐ только если реально используем
**Условие приза:** показать, **как Codex реально помог строить**. $100 на человека (личная ссылка в Hackerpack, 30 дней).
**Как честно:** один человек (роль B) пишет в Codex изолированные куски: детекторы (`cfar`, `sprt`, корреляция) с юнит-тестами и eval harness. Доказательства: ссылки на задачи/PR Codex, скриншоты, `docs/codex-log.md` («задача → что сделал Codex → что поправили»), в сабмите честно, кто что писал.
**Решение на шаге 0 плана (Пт 21:30):** есть человек — Codex остаётся; нет — снимаем его из тех-челленджей, в том числе в preliminary. Задним числом лог не пишем.

## 6. CUT (не берём)
- **Gemma.** EmbeddingGemma на CPU — лишняя интеграция, эмбеддинги уже даёт Gemini.
- **Nemotron.** Силён в картинках и видео, а у нас текст.
- **Modal / Verda.** Им нужно, чтобы GPU был центральным. Нам GPU не нужен.
- **Aiven.** Postgres + pgvector в Docker на VPS проще и держит всё на Hostinger.
- **CRACI.** CI на их раннере не добавляет ничего к детекции, а судят глубину интеграции.

Полный канонический список CUT: [architecture.md](architecture.md#объём-must--should--cut).
