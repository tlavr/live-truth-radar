## 4. Топ-идеи с комбинациями (основной + тех)

### 🥇 1. «AimoLink»: доверенный агент закупок для кухни → **Trusted Trade Agents** (€4k)
**Что:** MCP-сервер поверх mock API Valio Aimo + агент шефа. Пример: «1000 л безлактозного молока к понедельнику» → поиск, цены, наличие → заказ сам, если < лимита, иначе карточка «одобрить» человеку. Замены по рецепту и аллергенам (школа/больница), журнал «что агент сделал и почему».
**Почему сильно:** самый большой приз среди софтовых, есть готовый mock API, критерии понятные.
**Тех-стек:** Gemini или Nemotron (агент) · Aiven (Postgres для заказов + Kafka/ClickHouse для аудита) · Codex · Oxylabs (сверка цены Aimo с рынком, «честная ли цена», с источниками) · Modal/Verda (своя модель) · CRACI.
**Фишка для судей:** открытый стандарт (MCP + JSON Schema + подписанные «claims» о цене и наличии), политики в виде читаемого файла.

### 🥈 2. «Gym, где агенты спотыкаются» → **Break the Agent** (€3k + work trial)
**Что:** маленькая RL-среда с честной сложностью, например «диспетчер с ограниченным бюджетом» или «кухня с меняющимся складом», где надо планировать на несколько шагов вперёд и адаптироваться к новой информации. Эталонное решение (ваш скрипт) выигрывает у frontier-агента. Защита от «читов»: ничего не делать или остановиться рано = 0 очков.
**Фишка:** тайбрейкер = маленькая модель, дообученная на опыте среды → это прямо Gemma + Modal/Verda.
**Тех-стек:** Modal (тысячи прогонов, файнтюн через Modal Dojo) или Verda · Gemma (маленькая модель, которая учится) · Nemotron (как второй агент для сравнения) · Aiven ClickHouse (логи прогонов) · Codex.
**Комбо-бонус:** одна и та же «кухня» может быть и средой для Break the Agent, и тестовым полигоном для идеи №1 (но сабмит один основной челлендж!).

### 🥉 3. «Live Price Pulse»: живой индекс цен Финляндии → **The Web Is Your Real-Time Database**
**Что:** «Scrape the Economy»: каждые N минут собираем цены корзины продуктов/электроники/аренды по магазинам Финляндии и Европы → строим живой индекс инфляции и алерты «молоко подорожало на 12% за неделю у X». Можно добавить вакансии как индикатор рынка труда.
**Тех-стек (самый «жирный»):** Context.dev (мониторы + вебхуки, извлечение по схеме) · Oxylabs (гео-таргетинг: одна вещь, разные страны) · Aiven (Kafka поток + ClickHouse/Tiger Data таймсерии) · Gemini (объяснение «почему») · Cloudinary (карточки-графики для шаринга) · CRACI.
**Переиспользование:** этот же движок даёт бенчмарки для S-Pankki («ты тратишь на еду больше среднего, потому что цены выросли на 8%»).

### 4. «Kela Butler»: агент, который находит, какие льготы и права тебе положены → **Internet Butler (Exa)**
**Что:** для новичков в Финляндии/студентов: «Мне повысили аренду на 15%, это законно?», «Какие пособия положены семье?». Агент ищет по свежим источникам (Kela, Vero, законы), показывает цитаты, заполняет черновик заявления, финальная кнопка за человеком.
**Тех-стек:** Exa (обязательно, ядро) · Oxylabs и/или Context.dev (чтение полных страниц, мониторинг изменений правил) · Gemini · ElevenLabs (голосовой режим) · Aiven.

### 5. «Swarm Radar»: детектор координированных бот-кампаний → **Decode the Noise (Hostinger)**
**Что:** не «один пост = пропаганда?», а поиск роя: одинаковые тексты, синхронные посты, сеть ссылок. Объяснение простым языком + честные метрики (precision, false positive rate) на размеченном наборе. Деплой на Hostinger VPS.
**Тех-стек:** Context.dev (скрейп соцсетей и новостей) · Oxylabs · Gemma/Nemotron на Modal или Verda (дёшево классифицировать много текста) · Aiven OpenSearch (поиск похожих текстов).

### 6. «Three Baskets Coach» → **Personal Economic Trainer (S-Pankki)**
**Что:** мобильный веб-чат: «Сколько я потратил на такси?», «Что безопасно потратить на этой неделе?». Автоматически раскладывает траты на 3 корзины (обязательные регулярные / обязательные неожиданные / «утекающие» мелочи). Симулятор «а если -20% ресторанов» и сравнение со Статистикой Финляндии.
**Тех-стек:** Verda (открытая модель в Европе: банковские данные не уходят чужому API, это прямо пример в описании Verda!) · Gemini или Gemma · Aiven Postgres · ElevenLabs (голос).

### 7. «Evidence Card» для AI-кода → **Earned Trust in AI Code (Tieto)** + **CRACI** + **Entire** + **Codex**
**Что:** каждое PR от агента приходит с «карточкой доказательств»: требование → что изменено → тесты → какие зависимости добавились (SBOM от CRACI) → куда код ходит в сеть (network traces CRACI) → уровень риска → что AI отказался решать. Низкий риск = лёгкая проверка человеком, высокий = полный ревью.
**Почему сильно:** CRACI, Entire (Trails = PR для агентов) и Codex здесь не «для галочки», а часть сути. Редкое естественное попадание 3-4 тех-челленджей.

### 8. Для любителей железа
- **Intel Physical AI** (€5k, но задача фиксированная, 25 станций): нужны ML/роботы. Плюс **Verda** (обучение VLA на их GPU) + **Qualia** (почистить демонстрации).
- **Green Renaissance + Arduino UNO Q + Atech:** например, «умный компостер/датчик пищевых отходов в столовой», который камерой распознаёт выброшенную еду и считает CO₂. Двойной зачёт Arduino (основной + тех).

### 9. Ещё идеи коротко
- **Wikipedia Through Time:** «Как переписывали историю»: ползунок по годам, показывает, как менялась статья о событии (Зимняя война), где были войны правок. SVT + RAG = бонус. + Verda (batch-эмбеддинги всего датасета) + Gemini.
- **Make Blueprints Talk:** гибрид: OCR/CV находит таблицы и подписи → дешёвая модель отвечает → ответ с рамкой на чертеже. Критерий «низкая стоимость» → Gemma на Modal или Nemotron (читает PDF/картинки). + Cloudinary (кропы и подсветка областей).
- **Make Unicorns Real:** «Кто реально ведёт раунды как наш?» Фаундер вводит свой сайт → Context.dev вытаскивает бренд и описание → Cala находит лидов, которые инвестировали в похожие компании за последний год → готовый список с тёплыми контактами. Как раз к Slush.
- **Spread:** если в команде есть алгоритмист: ценообразование + аукцион для водителей. Отдельный плюс: рейтинг виден сразу, можно играть параллельно с основным проектом (но сабмит только один).
