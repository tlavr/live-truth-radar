## 2. Ядро: «Claim Engine» (машина проверки утверждений)

Пять кубиков Lego, каждый переиспользуется:

```
  ВХОД               1. ИЗВЛЕЧЬ         2. НАЙТИ ДОКАЗАТЕЛЬСТВА    3. ВРЕМЯ             4. СИГНАЛЫ ОБМАНА      5. ВЕРДИКТ
 текст / URL /  →   утверждения     →  Cala · Wikipedia(RAG)  →  как менялось     →  приёмы манипуляции  →  ✅ / ⚠️ / ❌ +
 фото / кадр        и сущности         · живой веб               (SVT, старые        бот-паттерны,          объяснение простыми
 из очков           (кто, что, когда)  (Context.dev, Oxylabs)    версии страниц)     координация            словами + ссылки
```

**Пример на одном утверждении:** «Стартап X — лидер рынка, поднял €10M от Y».
1. Извлекли: компания X, сумма €10M, инвестор Y.
2. Cala: раунд был €3M, Y участвовал, но не лидировал. Веб: пресс-релиз от 2024.
3. Время: на сайте X в марте писали «€3M», в октябре стало «€10M».
4. Сигнал: «лидер рынка» без источника = *fabricated authority*.
5. Вердикт: ⚠️ «Преувеличено: €3M, а не €10M (источники: …)».

**Общие технические куски:** извлечение утверждений через LLM (JSON-схема) · модуль поиска доказательств с адаптерами (Cala / MariaDB / веб) · хранилище версий · классификатор приёмов манипуляции · генератор вердикта с цитатами · одна карточка UI «утверждение → вердикт → источники».

## 3. Четыре «обёртки» над ядром

### #4 Decode the Noise → «Source Truth Radar» 🏆 €2000
- **Демо:** вставляешь URL статьи или аккаунта → подсвечены приёмы манипуляции с объяснением, оценка источника (возраст домена, клон-контент, сеть ссылок), утверждения проверены по вебу.
- **Из ядра:** шаги 1, 2, 4, 5 (основное — шаг 4).
- **Добавить:** размеченный тестовый набор + страница с **precision и false positive rate** (это 40% оценки!); **деплой на Hostinger VPS** (обязательно).
- **Тех-челленджи:**
  - **Gemma / Nemotron** на **Modal** или **Verda**: дешёвый классификатор приёмов на большом объёме текста.
  - **Context.dev:** скрейп статей, соцсетей, бренд/провенанс домена, мониторы.
  - **Oxylabs:** чтение полных страниц, «что говорят ChatGPT/Perplexity об этом».
  - **Aiven OpenSearch:** поиск повторов текста (копипаста = бот-сеть).
  - **Gemini, Codex, CRACI** — универсальные.
- **Риск:** нужно честно измерить качество; деплой на чужой VPS.

### #11 AI Glasses → «Look & Verify» 🏆 Ray-Ban Meta каждому + форум Meta 18.11
- **Демо:** смотришь на стенд стартапа на Slush, на рекламу или заголовок газеты → очки говорят в ухо: «Компания X, раунд €3M в 2025 от Y. Фраза „лидер рынка“ не подтверждается». Или для слабовидящих: читает упаковку и проверяет обещания («эко», «без сахара»).
- **Из ядра:** шаги 1, 2, 5 + быстрый голосовой ответ.
- **Добавить:** приложение через Device Access Toolkit (iOS/Android) или веб-апп; работа с разрешениями, обрывом связи, согласием (это часть критериев).
- **Тех-челленджи:**
  - **Gemini:** живое распознавание кадра/видео (сильная сторона).
  - **Nemotron VL:** читает картинку и документ одной моделью.
  - **ElevenLabs:** естественный голос ответа.
  - **Cloudinary:** обрезка/улучшение кадра перед распознаванием.
  - **Context.dev:** по логотипу → бренд и компания.
  - **Modal** — для быстрого бэкенда.
- **Риск:** очков всего 20 на весь хакатон; нужен мобильный разработчик.

### #12 Make Unicorns Real → «Pitch Truth Check» 🏆 ≈€5000 + €1000 кредитов
- **Демо:** инвестор вставляет pitch deck (PDF) или сайт стартапа → за 60 секунд список утверждений с вердиктами по данным Cala: раунды, инвесторы, команда, конкуренты, которые только что подняли деньги. Плюс «вопросы, которые стоит задать фаундеру». Готово к Slush.
- **Из ядра:** шаги 1, 2, 3, 5 (Cala = главный источник шага 2).
- **Добавить:** парсинг pitch deck, сравнение с конкурентами из графа Cala.
- **Тех-челленджи:**
  - **Context.dev:** сайт стартапа → описание, бренд, новости, мониторы изменений (+ «как менялись заявления на сайте»).
  - **Oxylabs:** свежие новости и сверка вне Cala.
  - **Gemini** (или **Nemotron**): чтение PDF-деков.
  - **Aiven:** хранение проверок, кэш.
  - **Codex, CRACI.**
- **Плюсы:** самый большой приз из четырёх, критерии простые (боль, исполнение, оригинальность, Cala в ядре), свежий угол («проверка правды», а не очередной CRM).

### #19 Wikipedia Through Time → «History Rewind» 🏆 €1000 + €1000 UpCloud + сертификаты
- **Демо:** выбираешь статью по истории Финляндии → ползунок по годам; видно, как менялся текст, где были **войны правок** и кто их вёл; RAG-ассистент отвечает: «Что Википедия говорила об этом в 2015 и что изменилось?» со ссылками на конкретную версию.

- **Тех-челленджи:**
  - **Verda:** batch-эмбеддинги всего большого датасета (прямо их пример) + inference API.
  - **Gemma** (EmbeddingGemma, мультиязычная) или своя модель на **Modal**.
  - **Gemini:** ответы и сравнение версий.
  - **Codex.**
  - MariaDB-ассет (публикация на mariadb.org).
  - ⚠️ Aiven сюда хуже: основная БД должна быть MariaDB.
- **Плюсы:** бонус за SVT/оба трека; меньше конкуренция по деньгам. **Минус:** самый маленький приз.
