# Архитектура Live Truth Radar

*Урезанный объём под хакатон: делаем ядро глубоко, а не всё поверхностно. Пошаговый план и чекпоинты: [HANDOFF.md](HANDOFF.md#5-план-по-шагам).*

## Как работает (для ребёнка)
Представь **дежурного детектива**, который сидит на Hostinger и **каждые несколько минут смотрит в интернет** через бинокль Context.dev.
1. Собирает новые статьи и посты по нескольким темам.
2. Замечает, что **17 аккаунтов за 10 минут написали почти одно и то же** → «рой!».
3. Читает тексты и говорит: «Тут **запугивание**: „если не сделаете X, завтра будет катастрофа“, без фактов».
4. Честно говорит, **насколько уверен**, и показывает, как часто он ошибается (метрики).

## Объём: MUST / SHOULD / CUT
| Уровень | Что | Когда |
|---|---|---|
| **MUST** | Ingest, Swarm Detector, объяснение вердикта (Gemini), Eval, простой дашборд, деплой на Hostinger | К сб ~20:00 |
| **SHOULD** | Source Trust (Context.dev brand/company), Oxylabs гео-`/search` в карточке, SemEval-подвыборка для метрик приёмов | Сб вечер, только если MUST работает |
| **CUT** | Fact-check, Change Watch, Context.dev monitors/webhooks (заменены поллингом), Oxylabs «ответы AI-ассистентов», Gemma, спектрограммы, delay-Doppler, бот-датасеты TwiBot/Cresci | Только в слайд «что дальше» |

## Схема (MUST)
```
          ┌──────────────── Hostinger VPS (Docker Compose, публичный HTTPS-домен) ───────────┐
 ВЕБ      │                                                                                   │
 новости ─┼─► worker: поллинг Context.dev каждые N мин ──► db: Postgres + pgvector            │
 соцсети  │   (news search + social scrape)                  (items, actors, embeddings,     │
          │                                                   findings, labels)              │
          │   worker: эмбеддинги Gemini → matched filter → корреляция аккаунтов              │
          │           → CFAR → SPRT → вердикт → объяснение Gemini (приём + цитата)           │
          │                                                                                   │
          │   api: FastAPI (REST + отдаёт дашборд)  ──►  дашборд: алерты, карточка, метрики │
          │   eval: синтетический рой в живом потоке → ROC, precision, FPR, время до решения │
          └───────────────────────────────────────────────────────────────────────────────────┘
             LLM: Gemini (основной) · Hostinger AI Router (запасной, тот же OpenAI-совм. клиент)
```

## Модули
| # | Модуль | Уровень | Что делает | Тулы |
|---|---|---|---|---|
| 0 | **Live Ingest** | MUST | Каждые N минут (2–5) тянет свежие статьи и посты по 3–5 темам, сохраняет текст, автора, время, URL | Context.dev news search + social scrape |
| 1 | **Swarm Detector** | MUST | Matched filter (нарратив по эмбеддингам) → кросс-корреляция активности аккаунтов → CFAR (всплеск) → SPRT (решение) + SNR в дБ | Gemini embeddings + наш код (numpy/scipy) |
| 2 | **Explain / Technique** | MUST | Для кластера: приём манипуляции + цитата-доказательство + уверенность + объяснение простыми словами | Gemini structured output (длинный контекст на весь кластер) |
| E | **Eval Harness** | MUST | Инжекция синтетического роя в живой поток, ROC (Pd vs Pfa), precision, FPR, «постов/секунд до решения»; порог «не уверен» | Наш код + LLM для генерации вариаций роя |
| UI | **Radar Dashboard** | MUST | Лента алертов, карточка вердикта (посты, тайминг, SNR, SPRT-трасса, приём), страница `/metrics` | Статический HTML + JS + Chart.js, отдаёт FastAPI |
| 3 | **Source Trust** | SHOULD | Кто стоит за доменом: компания, возраст, чужое лого | Context.dev brand + company enrichment |
| 4 | **Geo Echo** | SHOULD | Тот же нарратив в других странах? Живой вызов + URL источников в карточке | Oxylabs `/search` с гео |
| — | Fact-check, Change Watch | CUT | — | — |

## Стек на VPS (Docker Compose)
| Сервис | Что внутри |
|---|---|
| `caddy` | Reverse proxy + автоматический HTTPS для домена Hostinger |
| `api` | Python, FastAPI: REST для дашборда, отдаёт статический дашборд |
| `worker` | Python: поллинг Context.dev, детекторы (numpy/scipy), вызовы Gemini, eval |
| `db` | Postgres + pgvector |

Фронт без сборки (HTML + JS + Chart.js), чтобы не тратить время на тулчейн. Это решение по умолчанию: если в команде есть человек, который быстро делает React, можно поменять, не трогая остальное.

## Хранилище
Таблицы: `actors` (аккаунт/автор), `items` (пост/статья: текст, автор, время, URL, источник, флаг `synthetic`), `embeddings` (pgvector), `findings` (вердикт, LLR, SNR, объяснение), `labels` (ручная разметка).
Ответы Context.dev кэшируем у себя (повторный запрос стоит тех же кредитов).

## Данные для метрик (40% оценки!)
| Уровень | Набор | Для чего |
|---|---|---|
| MUST | **Синтетический рой:** LLM пишет ~30 вариаций одного месседжа, разносим по фейковым аккаунтам с лагами, прячем в реальные посты (`synthetic = true`) | ROC и время до решения для Swarm Detector |
| MUST | **Ручная разметка ~50 живых примеров** (органика / подозрительно), ~1 час на команду | Честный live test set, FPR на реальных людях |
| SHOULD | **SemEval-2020 Task 11** (Propaganda Techniques Corpus), подвыборка | Precision классификатора приёмов. Проверить лицензию и скачивание |
| CUT | TwiBot-20/22, Cresci-2017 | Доступ по запросу, не успеем |

## Демо-сценарий на 2 минуты
1. Открываем `https://<домен Hostinger>`: лента живых алертов по 3–5 темам (обновляется поллингом).
2. Нажимаем «инжектировать тестовую кампанию» → через несколько минут/постов появляется алерт «🐝 Рой: 17 аккаунтов, SNR из −8 до +11 дБ».
3. Карточка: посты, тайминг, SPRT-трасса («решение на 3-м посте»), приём «🎭 Fear appeal» с подсветкой фраз и объяснением.
4. (SHOULD) «🔗 Источник: …» от Context.dev и «🌍 то же в EE/DE» от Oxylabs с URL.
5. Страница `/metrics`: ROC, рабочая точка, precision/FPR, примеры ошибок.

## Главные риски
| Риск | Что делаем |
|---|---|
| Social scrape Context.dev не отдаёт автора или время | **Проверить первым делом (шаг 1 плана).** Запасной вариант: news search + синтетический рой; авторы = домены/авторы статей |
| Мало реальных роёв за выходные | Инжекция тестовой цели: это и метрика, и демо |
| Лимиты Gemini | Hostinger AI Router как запасной LLM; эмбеддинги кэшируем |
| Деплой ломается в последний момент | Деплой с первого часа, фича-фриз в вс 06:00 |
